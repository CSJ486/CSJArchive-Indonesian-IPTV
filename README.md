# CSJArchive-Indonesian-IPTV
ENG: This is an M3U that uses IPTV for Indonesian television.
IND: Ini adalah M3U yang pake IPTV untuk buatan Indonesia

Channel ini gua akan ditambah dan diupdate pada pukul seberapapun, kalau channel akan mati sementara.

Disini ada channel berada dikoleksi:
TV Nasional (30+)
Movies (Cuma 1 deh...)
Sports (10+ itu diambil oleh (beetv.my.id)[beetv.my.id))
DensTV (43 itu diambil oleh (dens.tv)[dens.tv])
CCTV (160 disini ada Merekam footage yang berada di-lokasi Gunung Kidul, Yogyakarta)
